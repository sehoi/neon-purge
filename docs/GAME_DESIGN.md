# NEON PURGE — 게임 기획서

> 버전 0.1 · 2026-08-14 · 탑다운 생존 액션 (뱀서라이크)

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| **타이틀** | NEON PURGE (네온 퍼지) |
| **장르** | 탑다운 생존 액션 / 로그라이트 |
| **플랫폼** | 웹 브라우저 (데스크톱 우선, 모바일 터치 대응) |
| **플레이 인원** | 1인 |
| **1회 플레이 시간** | 10분 (보스 처치 시 클리어) |
| **기술 스택** | HTML5 Canvas 2D + 순수 ES 모듈 (빌드 도구·외부 라이브러리·에셋 파일 **0개**) |

### 한 줄 컨셉
> 감염된 메인프레임에 투입된 백신 프로그램이 되어, 10분간 밀려드는 악성코드를 정화하고 커널 바이러스를 삭제한다.

### 왜 이 설계인가 (제작 속도 관점)
- **에셋 제로**: 모든 그래픽은 벡터 도형 + 네온 글로우, 모든 사운드는 WebAudio 절차 생성. 그림·음악 리소스 제작 시간이 통째로 사라진다.
- **자동 공격**: 조작이 "이동 + 대시" 둘뿐. 조준·콤보 튜닝 비용이 없고, 그만큼 밸런싱에 시간을 쓸 수 있다.
- **평면 월드**: 지형·충돌맵·레벨 디자인이 없다. 무한 평면 + 스폰 테이블만으로 15분치 콘텐츠가 나온다.
- **데이터 주도**: 무기/적/업그레이드가 전부 테이블. 숫자만 고쳐서 밸런싱하고, 새 콘텐츠는 배열에 한 줄 추가하면 끝난다.

## 2. 코어 루프

```
 이동으로 적을 유인·회피
        ↓
 무기가 자동으로 발사 → 처치
        ↓
 데이터 셰이드(XP) 드랍 → 흡수
        ↓
 레벨업 → 강화 카드 3택 1
        ↓
 빌드가 강해짐 ⟷ 적이 더 강해짐
        ↓
 10:00 커널 바이러스 처치 = 클리어
        ↓
 코드 조각 획득 → 영구 업그레이드 → 다음 런
```

**설계 의도**: 20~40초마다 레벨업이 오도록 XP 곡선을 맞춘다. "다음 카드까지 조금만 더"라는 리듬이 10분을 끌고 가는 유일한 엔진이다.

메타 업그레이드 `프리페치`로 시작 레벨을 올렸다면, **그만큼의 강화 카드를 시작 시점에 고르고 들어간다.** 레벨만 오르고 고를 기회가 없으면 산 의미가 없다.

## 3. 조작

| 입력 | 동작 |
|---|---|
| `WASD` / 방향키 | 8방향 이동 |
| `Space` | 대시 — 이동 방향으로 순간 전진, 0.25초 무적. 쿨다운 1.8초 |
| `1` `2` `3` | 레벨업 카드 선택 (마우스 클릭도 지원) |
| `Esc` / `P` | 일시정지 |
| `R` | 결과 화면에서 재시작 |

공격은 **전부 자동**. 플레이어가 조준하지 않는다.

### 터치 조작 (모바일)

| 입력 | 동작 |
|---|---|
| 화면 왼쪽 드래그 | 이동 — 누른 자리가 조이스틱 중심이 된다 |
| 오른쪽 아래 원 | 대시 |
| 상단 중앙 `▮▮` | 일시정지 |
| 카드 탭 | 강화 선택 |

설계 규칙:

1. **전투 중 터치와 UI 터치를 분리한다.** 전투 중에는 화면 좌측이 조이스틱, 지정된 두 원이 버튼이고, 그 외 영역의 탭은 무시한다.
2. **조이스틱 손가락은 UI 포인터를 움직이지 않는다.** 두 값을 공유하면 스틱을 끌 때마다 버튼 히트테스트가 손가락을 따라다닌다.
3. **키보드에만 있는 기능은 화면에 버튼이 있어야 한다.** 모바일에는 `Esc`가 없으므로 일시정지 버튼이 없으면 판을 끝낼 방법이 사라진다.
4. **상태가 바뀌는 순간 닿아 있던 손가락은 무시한다.** 조이스틱을 쥔 채 레벨업이 뜨면, 손을 떼는 `pointerup`이 "화면 왼쪽 탭"으로 해석되어 첫 카드가 제멋대로 선택됐다. 그 손가락은 새 화면에 대한 입력 의사가 아니다.
5. **중요한 정보는 화면 위쪽에 둔다.** 체력바와 로드아웃이 하단에 있으면 조이스틱과 대시 버튼을 쥔 손에 가려진다 — 정작 제일 자주 봐야 할 체력이 안 보인다. 터치 기기에서는 체력·레벨·처치를 좌상단, 무기·강화 아이콘을 우상단에 배치한다.

### 화면 채우기
논리 해상도는 높이 720을 고정하고 **폭만 화면 비율에 맞춘다**(1280~1750). 16:9로 못박으면 20:9인 요즘 폰에서 좌우에 검은 띠가 생겨 화면의 20% 가까이가 낭비된다. 폭을 늘리면 띠가 사라지고 그만큼 더 넓게 보인다.

가로 모드에서 노치는 좌우에 온다. 캔버스를 `safe-area-inset`만큼 비켜 배치하지 않으면 화면 끝 HUD(특히 상단 경험치 바)가 잘린다. 경험치 바 자체도 터치에서는 두껍게(6 → 10px) 그리고 가장자리에서 띄운다 — 축소 스케일에서 6px는 사실상 보이지 않는다.

판을 시작할 때 전체화면을 요청한다. 주소창과 하단 바가 세로 공간을 크게 갉아먹기 때문에, 없애는 것만으로 체감이 확연히 달라진다. 실패하는 기기(iPhone Safari)에서도 게임은 그대로 진행된다.

세로로 들면 화면이 손톱만해지므로, 세로일 때는 게임을 멈추고 회전 안내를 띄운다.

## 4. 플레이어

| 스탯 | 초기값 | 비고 |
|---|---|---|
| 최대 체력 | 100 | |
| 이동 속도 | 245 px/s (터치 285) | 속도감 우선. 적 속도도 함께 올려 추격감을 유지한다 |
| 히트박스 반지름 | 10 px | 적 히트박스보다 넉넉히 작게 (억울한 피격 방지) |
| 피격 무적 | 0.7 s | 피격 시 깜빡임 |
| 픽업 자석 범위 | 105 px | 데이터 흡인 없이도 줍는 맛이 나야 한다 |
| 대시 거리 / 쿨다운 | 155 px (터치 175) / 1.8 s | 대시 중 0.25s 무적 |

> 자석 범위와 이동 속도는 "기본값이 너무 답답하다"는 판단으로 올렸다. 자석은 60 → 105로, 데이터 흡인을 찍지 않아도 처치한 자리의 경험치가 알아서 따라오게 했다. 데이터 흡인은 여기서 다시 +25%/레벨이므로 만렙에서 236px로 여전히 값어치가 있다.
>
> 터치에서는 화면 폭이 1280 → 1480 안팎으로 넓어져 같은 속도가 더 굼떠 보인다. 넓어진 비율만큼 올려 체감을 맞춘다.

**비주얼**: 시안색 삼각형 + 진행 방향 트레일. 피격 시 흰색 플래시 + 화면 흔들림.

## 5. 무기 (5종)

모든 무기는 레벨 1~5. 레벨 5 도달 + 지정 패시브 보유 시 **진화**한다.

| # | 무기 | 동작 | Lv1 수치 | Lv5 수치 | 진화 조건 | 진화형 |
|---|---|---|---|---|---|---|
| W1 | **충격 파동** | 플레이어 중심에서 퍼지는 원형 충격파 (시작 무기) | 데미지 12, 반경 105, 주기 1.15s | 데미지 25, 반경 165, 주기 0.85s | + 출력 증폭 | **초신성** — 반경 2배, 적을 밀어냄 |
| W2 | **추적탄** | 가장 가까운 적을 자동 조준하는 탄환 | 데미지 12, 1발, 주기 0.8s | 데미지 22, 4발, 주기 0.45s | + 클럭 가속 | **레일건** — 관통, 데미지 3배 |
| W3 | **궤도 노드** | 플레이어 주위를 도는 궤도 오브, 접촉 데미지 | 데미지 10, 1개, 반경 70 | 데미지 20, 4개, 반경 95 | + 기동 강화 | **전류 결계** — 노드 사이를 전류가 연결 |
| W4 | **연쇄 방전** | 최근접 적 → 인접 적으로 튀는 번개 | 데미지 14, 2회 튐, 주기 1.6s | 데미지 26, 6회 튐, 주기 1.0s | — | — |
| W5 | **관통 빔** | 플레이어를 관통해 화면을 가로지르는 회전 빔 | 데미지 20/틱, 1줄, 주기 3.0s | 데미지 34/틱, 3줄, 주기 2.0s | — | — |

**작명 규칙**: 카드에 뜬 이름만 보고 "무엇을 하는 무기인가"를 알 수 있어야 한다. 세계관 분위기는 그다음이다 — 멋있어 보이려고 기능을 흐리지 않는다. 초기 이름(펄스 링, 트레이서, 오빗 노드…)은 영어 음차라 기능이 읽히지 않았다.

**보유 한도**: 무기 최대 4종 (5종 중 4개까지). 한도에 차면 신규 무기 카드가 등장하지 않고 레벨업 카드만 나온다.

**설계 의도**: 각 무기가 서로 다른 "공간"을 담당한다 — 충격 파동(근접 전방위), 추적탄(단일 원거리), 궤도 노드(호위), 연쇄 방전(군집 처리), 관통 빔(라인). 어떤 2~3개를 조합해도 빈틈이 메워지도록.

> **궤도 노드는 회전이 눈에 보여야 한다.** 초기값(한 바퀴 2.6초)은 이동 중에 "도는 것"으로 읽히지 않고 그냥 붙어다니는 점처럼 보였다. 회전 속도를 1.5배(137°/s → 206°/s)로 올리고 오브 뒤에 짧은 궤적 호를 그려 회전을 드러냈다.

## 9. 픽업

적은 처치 시 자신의 `xp` 값만큼 경험치를 떨어뜨린다. **픽업의 겉모습은 그 값에서 자동으로 결정된다** — 강한 적이 더 큰 조각을 떨군다는 사실이 눈으로 바로 보여야 하기 때문이다.

| 등급 | 조건 | 모양 |
|---|---|---|
| **데이터 셰이드** | XP 1~2 | 작은 라임색 마름모 (r 5) |
| **데이터 코어** | XP 3~9 | 중간 금색 육각형 + 링 (r 9.5) |
| **데이터 프라임** | XP 10+ / 엘리트 확정 | 큰 백색 팔각형 + 헤일로 (r 14) |

드랍 시 7% 확률로 값이 ×3, 1% 확률로 ×8이 되어 등급이 함께 올라간다. 웜(XP 1)은 셰이드, 파이어월 샤드(XP 3)는 항상 코어가 나온다.

| 아이템 | 드랍률 | 효과 |
|---|---|---|
| **복구 팩** (민트, 십자) | 처치 시 0.8% | 체력 30% 회복 |
| **EMP** (시안, 삼각) | 처치 시 0.4% | 화면 내 전체 적에게 300 데미지 |
| **자석** (보라, 오각) | 처치 시 0.4% | 필드의 모든 XP 즉시 흡수 |

### 적과 픽업의 구분 규칙 (중요)
난전 중 둘을 혼동하면 게임이 읽히지 않는다. 색이 아니라 **실루엣**으로 가른다.

- **적은 예외 없이 속이 빈 외곽선 도형**, 색은 마젠타~레드 계열로 한정
- **픽업은 예외 없이 속이 꽉 찬 밝은 도형** + 중심 코어 + 맥동, 색은 라임~금~백색 계열
- 흡인 중인 픽업은 1.25배로 커져 "지금 오고 있다"를 알린다
- 같은 변 수를 쓰는 적끼리는 회전으로 가른다 — 파이어월 샤드는 회전하지 않는 축 정렬 정사각형, 스팸봇은 빠르게 도는 작은 마름모

**XP 곡선**: 다음 레벨 필요량 `= 4 + round(level × 2.5) + floor(level² × 0.35)`
→ Lv1→2: 7, Lv10→11: 64, Lv30→31: 394. 10분 런에서 **Lv 28~34** 도달을 목표로 튜닝.

## 10. 레벨업 강화 카드

레벨업 시 게임이 정지하고 카드 3장이 제시된다.

**추첨 규칙**
1. 후보 풀 = (미보유 무기 + 보유 무기 레벨업 + 미보유 패시브 + 보유 패시브 레벨업 + 진화)
2. 진화 조건 충족 시 해당 진화 카드는 **가중치 ×10** (거의 확정 등장)
3. 보유 슬롯이 꽉 차면 신규 항목 제외
4. 모든 후보가 만렙이면 → 소모품 카드 (체력 전회복 / 코드 조각 +50 / 일시 무적 10초)
5. 카드 3장은 중복 없이 뽑는다

**희귀도 연출**: 진화 카드는 금색 테두리 + 전용 SFX.

## 11. 메타 진행 (영구 업그레이드)

런 종료 시 **코드 조각**을 획득한다: `처치 수 × 1 + 생존 초 × 0.5 + 클리어 보너스 500`

타이틀 화면 → `업그레이드` 에서 소비:

| 항목 | 단계 | 비용 (단계별) | 효과 |
|---|---|---|---|
| **코어 출력** | 5 | 100 / 200 / 400 / 800 / 1600 | 모든 무기 피해량 +4% / 단계 |
| **내구 강화** | 5 | 80 / 160 / 320 / 640 / 1280 | 시작 최대 체력 +10 / 단계 |
| **추진 강화** | 3 | 150 / 400 / 900 | 이동속도 +4% / 단계 |
| **선행 강화** | 3 | 120 / 300 / 700 | 시작 레벨 +1 / 단계 (시작 시 그만큼 카드를 고른다) |
| **긴급 재부팅** | 1 | 2000 | 런당 1회 부활 (체력 50%) |
| 부트 옵션 | 4 | 각 300 | 시작 무기를 W2~W5 중 선택 해금 *(미구현)* |

무기·강화와 같은 작명 규칙을 적용했다. 초기 이름(냉각 팬, 프리페치, 백업 스냅샷)은 전산 용어 은유가 너무 멀어서 **무엇을 사는 건지 알 수 없었다.**

저장은 `localStorage`.

**전체 초기화**는 조각·강화·기록·업적을 전부 지우며 **조각을 환불하지 않는다.** 되돌릴 수 없으므로 무엇이 사라지는지(보유 조각 수, 구매 단계 수)를 구체적으로 적은 확인 화면을 거친다. "리스펙(강화만 되돌리고 조각은 환불)"과 혼동하기 쉬워서, 확인 화면에 환불이 없다는 사실을 명시한다.

## 12. 업적

12개. 절반은 그냥 플레이하다 열리고, 절반은 일부러 노려야 열린다.

| 업적 | 조건 |
|---|---|
| 첫 접속 | 한 판을 끝까지 플레이 |
| 정화 완료 | 커널 바이러스 처치 |
| 대청소 | 한 판에 2,000마리 처치 |
| 심층 침투 | 레벨 25 도달 |
| 진화의 끝 | 진화 무기 2종 이상 보유한 채 클리어 |
| 한 자루로 충분해 | 무기 하나만 들고 클리어 |
| 파동만으로 | 충격 파동 계열만 들고 클리어 |
| 맨몸 | 강화를 하나도 고르지 않고 클리어 |
| 무결점 | 한 번도 맞지 않고 5분 생존 |
| 속전속결 | 9분 안에 클리어 |
| 재기동 | 부활한 뒤 그 판을 클리어 |
| 무기고 | 무기 4종을 모두 만렙 |

**설계 원칙**: 조건을 이름과 설명만 보고 알 수 있어야 한다. "운이 좋으면 열리는" 업적은 넣지 않는다. 판정은 런 종료 시 한 번만 하며(`data/achievements.js`의 `check(ctx)`), 새로 달성한 업적은 결과 화면에 표시된다.

새 업적을 추가하려면 테이블에 객체 하나를 더하면 된다. 조건이 런 요약(`world.runStats`)에 없는 값을 필요로 하면 그것부터 추적한다.

| 엘리트 / 보스 | `#ff6a00` (오렌지) |
| XP 셰이드 / 코어 / 프라임 | `#8cff3d` / `#ffd23d` / `#ffffff` |

적 팔레트(마젠타~레드)와 픽업 팔레트(라임~금~백색)는 **의도적으로 겹치지 않게** 나눠 두었다. 새 적이나 새 픽업을 추가할 때도 이 경계를 넘지 않는다.

### 스타일 규칙
- 모든 엔티티는 **채워지지 않은 벡터 도형** (선 굵기 2px) + `shadowBlur` 글로우
- 배경은 스크롤되는 격자. 플레이어 이동에 따라 패럴랙스(0.4배)
- **피드백 3종 세트**(체감 품질의 90%):
  - **히트 스톱** — 강한 타격 시 4~6프레임 정지
  - **화면 흔들림** — 피격/폭발 시 진폭 6~14px, 200ms 감쇠
  - **파티클** — 처치 시 도형 파편 6~10개가 튀며 페이드
- 데미지 숫자는 띄우지 않는다 (군집 전투에서 화면이 죽는다). 대신 히트 플래시로 표현
- 폰트: 시스템 모노스페이스 (`ui-monospace, monospace`)

### 오디오 (WebAudio 절차 생성, 파일 0개)
| 이벤트 | 합성 방식 |
|---|---|
| 발사 | 짧은 square 파형, 800→400Hz 스윕, 60ms |
| 히트 | white noise 버스트 + 하이패스, 40ms |
| 처치 | noise + 하강 sine, 120ms |
| 피격 | 저역 sawtooth 200→80Hz, 250ms |
| 레벨업 | sine 아르페지오 3음 (C-E-G), 400ms |
| 보스 등장 | 저역 sine 드론 + 노이즈 크레셴도 |
| BGM | 4음 베이스 아르페지오 루프 (120 BPM), 페이즈별 템포 상승 |

동일 SFX 동시 재생 상한 4개(클리핑 방지). 음소거 토글 필수.

## 14. UI 화면

1. **타이틀** — 로고, `시작` / `업그레이드` / `조작법` / `기록`, 배경에 데모 적들이 떠다님
2. **인게임 HUD**
   - 상단: 타이머 `12:34`, 처치 수, 레벨
   - 상단 폭 전체: XP 바 (얇게)
   - 좌하단: 체력 바 + 수치
   - 우하단: 보유 무기/패시브 아이콘 격자 + 레벨 점 표시
   - 대시 쿨다운: 플레이어 발밑 링 게이지
